Matrix product: a row meets a column

Each entry of C = A @ B takes one row of A and one column of B, multiplies them entry by entry, and adds. Click an entry of C, or press Play.

Type your own numbers into A and B: C is recomputed as you type.
A · (2, 3)
@
B · (3, 2)
=
C · (2, 2)
C has one entry for every (row of A, column of B) pair: 2 × 2 = 4 entries, each a sum of 3 products.
(2,3)@(3,2)→(2, 2)

The inner sizes must match (each row of A and each column of B have 3 entries) and disappear; the outer sizes give the shape of the result.

The faded rows of b are not stored anywhere: broadcasting reuses the one row for all B rows. In the backward pass this is why the bias gradient is a sum over the batch.

s2-l04

A dot product measures how well two vectors match

Attention compares vectors with the dot product, q · k = q₁k₁ + q₂k₂. It is large when the arrows point the same way, near 0 when they are at right angles, and negative when they point apart.

Drag the tip of either arrow (or use the slider).

With unit-length vectors, q · k = cos(angle): 1 when aligned, 0 at 90°, −1 when opposite.

Attention, one query at a time

Four tokens, each already turned into a query, a key and a value (here only 2 numbers each, so they can be drawn). Pick a token: its query is compared with every key, the scores go through a softmax, and the output is the weighted mix of the values.

Drag the orange query arrow in the left picture: the scores, weights and output follow live.
  1. Scores. One row of S = Q Kᵀ / √dₕ: the chosen query dotted with every key. Masked entries (keys after the query) are set to −∞ before the softmax.
  2. Softmax. The row becomes weights that are positive and add up to 1.
  3. Mix. The output is Σ weightⱼ · vⱼ: an average of the value vectors.

s2-l04

Why the scores are divided by √dₕ

With longer vectors, dot products of random entries grow: their spread is about √dₕ. Large scores push the softmax toward one winner, and the other keys then get almost no weight and almost no gradient. Move dₕ and compare one row of weights with and without the division.

Multi-head: the same vector, cut into heads

With d = 8 and h = 2 heads, each position's query, key and value vectors are cut into 2 pieces of dₕ = 4. Each head runs the attention above on its own pieces; then the pieces are joined again. A reshape cuts, a transpose moves the head axis next to the batch.

(B, T, 3d) → reshape (B, T, 3, h, dₕ) → transpose (3, B, h, T, dₕ) → q, k, v each (B, h, T, dₕ)
